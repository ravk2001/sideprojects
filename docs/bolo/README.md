# Bolo — temporary GitHub Pages preview

Upload this **bolo** folder into your repository's existing **docs** folder. The result should be docs/bolo/index.html and docs/bolo/workspace.html. Keep Settings → Pages configured for main /docs.

Expected URL: https://ravk2001.github.io/sideprojects/bolo/

This is a free static preview with the Bolo website, real speech sample, recorder, shared computer audio where supported, optional microphone, pause/resume, editing, folder selection, and Word/text/WAV exports. It has no accounts, checkout, support-ticket backend, or subscription enforcement.

Use HTTPS and desktop Chrome/Edge. First model use downloads English speech-model files from Hugging Face. Audio stays on the device. Export important recordings before changing browser/site address or clearing site data.

Do not upload the full server project's .env or .dev.vars files. This folder contains only public client assets.

Remove docs/bolo to take down this temporary preview. The existing app at docs/index.html is preserved.
